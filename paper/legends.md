# Figure legends

**Fig. 1 | NSCLC-Agent: a language model decides the consult; a deterministic kernel audits it from outside the loop.**
The clinician writes in Chinese or English, in a static web app (the Python code runs in the browser via WebAssembly) or at a command line; both reach the same session. In the main configuration, full model autonomy, the lead agent is a language model from any supported provider (blue). It decides the stage (cTNM and stage group, AJCC/UICC 9th edition), the biomarker category (NSCL-21 to NSCL-39), the treatment intent and the plan, each with a rationale. It works in a loop of reasoning and tool calls: it keeps a live plan and structured case notes, runs read-only tool calls concurrently and delegates focused questions to seven specialist sub-agents (blue). During the consult the tools only inform (trial registry, regimen library and reference doses, guidelines, clinical pathways, literature, prognosis cohorts, interactions, images and reports). The nine kernel decision tools are offered only in kernel-assisted mode (dashed). Five of the eight deterministic hooks (grey) are on: an emergency screen on each message, an evidence ledger after each tool call, and citation-provenance, dose-provenance and emergency-first checks on submission. Their findings return to the model, which revises or justifies an override; no hook blocks or rewrites. Hooks that compare the model with the kernel are off. After the consult the kernel reads the case independently and audits the model's decisions (vermillion arrow); the clinician sees the audit (/audit) and the evaluation scores it, but it never returns to the model. Governed mode, in which the kernel is the control plane, is a separate configuration (Extended Data Fig. 3). Counts are read from the code base when the figure is built. KB, knowledge base; MCP, Model Context Protocol; REPL, read–eval–print loop.

**Fig. 2 | The reference standard: stage is computed by a deterministic engine, and ambiguity is refused unless it cannot change the stage.**
**a**, Stage group assigned by the AJCC/UICC 9th-edition staging engine for every T and N category at M0. Under-specified descriptors (bare T1, T2 and N2; TX and NX) are shown below and to the right of the rules. A bare family is staged only when every subcategory gives the same stage group (for example, T1 N1 is IIA for T1a, T1b and T1c); otherwise it is refused (grey) and the engine names the test that resolves the ambiguity rather than guessing. TX N0 M0 is staged as occult carcinoma. **b**, Stage for each M category (T2a N0). Bare M1c is staged IVB because M1c1 and M1c2 agree; M1 and MX are refused. **c**, Accuracy of the deterministic pipeline on the gold-standard set (n = 70 cases: 42 end-to-end pipeline cases and 28 audit probes; denominators are the cases that test each property). Points show proportions; lines show exact (Clopper–Pearson) 95% confidence intervals. Vermillion, a lower value is better. In full autonomy the model stages the case itself; this engine and this set are the reference against which its decisions are audited (Figs 3 and 5).

**Fig. 3 | In full autonomy, the in-loop hooks catch provenance and emergency defects, and the independent audit catches the clinical-judgement defects.**
**a**, Clean consults were built from the 35 plans that the deterministic pipeline released for the gold-standard pipeline cases. One labelled defect was then injected into each consult, and three readers were run: the stop hooks that are on in full autonomy, the independent audit that runs after the consult, and the stop hooks of kernel-assisted mode. Cells show the number of consults in which the reader raised the expected finding (a dose figure counts whether named by the dose-provenance hook or by the rule engine's dose scan). Three defect classes apply to subsets: a wrong biomarker category (stage IV cases, n = 26), a regimen outside its declared population (stage 0–III, n = 9) and immunotherapy despite an actionable driver (stage IV with an actionable driver, n = 18). The bottom row shows clean consults with any finding (grey); the two warnings are ones the deterministic pipeline itself attaches (trial edition migration; progression on the same drug). **b**, For each defect class in full autonomy, the proportion of consults caught in the loop by the hooks, caught only afterwards by the audit, or caught by neither. A fabricated citation is caught only in the loop: the audit does not see which references the tools returned. The defects were constructed by the authors, so the experiment measures how much of the defect space each reader covers, not how often language models make these errors.

**Fig. 4 | Runtime properties: concurrent specialists and a bounded context.**
**a**, Wall-clock time of a multidisciplinary consult in full autonomy as a function of the number of specialist sub-agents, run one after another (grey) or concurrently (blue). Model calls were simulated with a fixed latency of 250 ms per call. Tools were real. Each specialist made two model calls and the lead agent made two. Points show medians of n = 5 repeats; bars show the range. Concurrency is capped at six worker threads, which accounts for the step at seven specialists. **b**, Estimated prompt size over a 24-turn consult (offline mock model, full autonomy) without compaction (grey) and with compaction (blue; context window 16,000 tokens; compaction triggered at 60%, dashed line). Open circles mark the turns at which compaction occurred. Token counts are provider-neutral estimates: one token per Chinese character and one per four other characters.

**Fig. 5 | A worked consult in full autonomy: the model decides a third-line stage IVB KRAS G12C case, the hooks catch two provenance errors, and the independent audit agrees with every decision.**
**a**, The case, summarised from a clinician's report: stage IVB adenocarcinoma with KRAS G12C, progressing after pembrolizumab–pemetrexed–carboplatin and then a KRAS G12C inhibitor, with MET amplification in ctDNA. **b**, Timeline of the consult. The lead agent recorded its case notes, then delegated to the radiologist, the medical oncologist and the evidence researcher, who ran concurrently, and submitted a draft. After the hooks' findings it looked up the library dose and checked the citation, and resubmitted. Model calls were simulated with a fixed latency of 0.6 s per call; tools, sub-agents and hooks were the real runtime (11 model calls, 4.2 s). No kernel decision tool was offered. **c**, The review loop. The model's decisions were scripted by the authors. The draft quoted doses from memory and cited a trial that does not exist (KRYSTAL-MET-7); the in-loop hooks raised two findings, shown verbatim, and the revision removed both errors without changing the decisions. **d**, The revised consult next to the kernel's independent reading after the consult: staging engine, M category from the metastatic sites, marker-level biomarker classifier, the deterministic pipeline's plan and the indication predicates of all 40 library regimens (Extended Data Fig. 4). The audit flagged the dose figure in the draft and nothing in the revision. Organ-function gates that remain open are listed for the clinician; they do not change the recommendation.

**Extended Data Fig. 1 | Tool access of the lead agent and the specialist sub-agents.**
Each column is a tool and each row an agent. Grey, the lead agent, which is the only agent that writes the case notes, updates the plan, delegates and submits the consult. Blue, the read-only allow-list of each built-in specialist sub-agent. Outlined cells and grey labels mark the nine kernel decision tools, which are offered only in kernel-assisted mode; in full autonomy no agent can call them. Specialists cannot delegate further or submit the consult. Custom specialists are declared in the same way: a name, a role, a prompt and a tool list.

**Extended Data Fig. 2 | The knowledge substrate of the clinical kernel.**
**a**, Recommendations in the built-in guideline knowledge base by source guideline. The 2,960 recommendations are machine-extracted and clinically unreviewed, are grouped in 147 cross-guideline clusters, and serve as non-releasable context only. **b**, Size of the deterministic kernel and of its evaluation set. **c**, Recommendations by guideline and topic; the nine most frequent topics are shown and the rest are pooled as other. **d**, Registry trials by treatment setting and by the 9th-edition stage groups they enrolled; a trial is counted once in every stage group it covers. In **c** and **d**, shading scales with the square root of the count and empty cells are zero. LA, locally advanced; TCM-WM, integrated traditional Chinese and Western medicine.

**Extended Data Fig. 3 | Release states of governed mode, the comparator configuration.**
In governed mode the kernel is a hard control plane rather than an auditor. A case passes through fixed steps (centre) and leaves at the first one that stops it (right). The critic can send the treatment plan back for repair a bounded number of times; a block finding that survives the loop stops release. A dose-bearing draft is produced only for an oncologist who opted in and only when every gate passes, and it still awaits sign-off by the tumour board, which is recorded outside the system. Any exception, and any divergence when a recorded run is replayed, fails closed, and a resumed run never reopens a safety decision. Counts are the release states of the 42 end-to-end gold-standard cases.

**Extended Data Fig. 4 | Every library regimen checked against the worked case.**
Each column is one of the 40 regimens in the library, grouped by setting; rows are the conditions of its declared, machine-executable indication predicate, read against the case notes of Fig. 5; the top row marks regimens whose predicate is met (6 of 40). Numbers on the right count the regimens that fail each condition. Outlines mark the regimens the model proposed (docetaxel–ramucirumab and docetaxel). A predicate checks the population only. The line of therapy is a separate check: first-line regimens stay eligible by population, and sotorasib meets its predicate although the record documents progression on a KRAS G12C inhibitor, which the rule engine reports as re-proposing a drug the disease progressed on. CM, CheckMate; CRT, chemoradiotherapy; Dato-DXd, datopotamab deruxtecan; KN, KEYNOTE; LCT, local consolidative therapy; SBRT, stereotactic body radiotherapy; SCLC, small-cell transformation; T-DXd, trastuzumab deruxtecan.
